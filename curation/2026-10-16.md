## Placement and release boundaries

- **PAWA:** placed with MultiWorld and other multi-agent simulators in §3.4. The GitHub badge explicitly says **Pipeline**: the linked repository releases the data-generation pipeline, not the predictive model implementation.
- **ObjDream:** placed in §2.4 because its predictive contribution is compact object-state supervision rather than pixel generation. Its [official repository](https://github.com/HuailiangMa/ObjDream) says “Code coming soon” and currently contains only a project introduction, so no code badge was added.
- **GeoThinker-F:** [Appendix M](https://arxiv.org/html/2610.20592v1) explicitly limits the method to current geometry and short-horizon future visual semantics. It is listed as predictive representation learning, not action-conditioned or long-horizon simulation. The code repository explicitly includes the F variant and its release.
- **Atomic-WAM:** the repository has released inference and RoboLab evaluation code; training code remains on its release plan. The README summary does not claim a complete training release.
- **ATAS:** its persistent registered geometry and time-indexed event memory satisfy §1.7's cross-shot-state criterion; multi-shot visual quality alone was not used as an inclusion reason.
- **OneLA / PreActIR:** no code badge was added because this review did not establish a released official implementation for either paper.
